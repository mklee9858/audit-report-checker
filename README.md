# 감사보고서 검증 프로그램

감사보고서의 Footing과 재무제표 본문·주석 간 Cross-check를 지원하는 Windows 프로그램입니다. 비교에 사용한 셀과 검증식을 확인하고, 필요한 계산식 조정과 예외 검토를 거쳐 Excel로 결과를 출력할 수 있습니다.

## 배포 버전

v2.17.2 · 실무 투입 전 테스트 단계

실행파일은 이 저장소의 **Releases**에서 제공합니다. 이 저장소에는 소개 자료와 사용법만 보관하며, 원본 소스코드는 포함하지 않습니다.

## 주요 기능

- 표별 가로·세로 Footing
- 재무제표 본문과 주석 간 Cross-check
- 본문·주석 원본 셀, 비교 금액, 차이 및 검증식 확인
- 비교식 조정, 검증 제외, 규칙 저장
- Excel CS 요약, 표별 검증 결과와 Cross-check 상세 출력
- 미검증·제외와 일치·불일치 결과 구분

## 만든 이유

보고서를 여러 번 수정하면서 합계 검산과 본문·주석 대사를 다시 수행하는 부담을 줄이기 위해 만들었습니다. 기존 Footing 서비스 이용 중 경험한 검증 오류와 불편을 개선하고, Cross-check를 함께 수행할 수 있도록 구성했습니다.

## 테스트와 적용 범위

8개 회사의 감사보고서로 테스트했고, 개발자가 확인한 범위에서 큰 작동 문제 없이 실행되는 것을 확인했습니다. 기존 서비스보다 Footing 검증 결과의 오류가 줄었다는 평가는 개발자의 정성적 관찰이며, 계량적 성능 비교 결과는 아닙니다. 실제 감사업무에는 아직 투입하지 않았습니다.

FALSE는 적용된 검증식에서 금액이 일치하지 않는다는 의미입니다. 실제 보고서 오류인지, 비교 대상이나 검증식의 문제인지는 원자료와 함께 검토해야 합니다.

## 데이터 처리 방식

정보 유출 우려를 고려해 업무 데이터를 외부 LLM에 전송하지 않는 구조로 설계했습니다. 개발에는 AI를 활용했지만, 프로그램 실행 중에는 구현된 처리 규칙과 수식·참조 관계로 데이터를 처리합니다.
